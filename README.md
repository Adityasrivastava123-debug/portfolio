# Aditya Srivastava — Portfolio

Personal portfolio website of **Aditya Srivastava** — Computer Science student at VIT Vellore (CSE, AI/ML specialization).

## About

A single-page portfolio built with plain HTML, CSS, and JavaScript — no build step, no frameworks.

## Sections

- Hero — intro and quick stats
- About — curious mind, builder mindset
- Skills — technical, interpersonal, creative
- Selected work — game & trailer, GNU Octave modeling, video resume
- Vision — the startup ambition
- Highlights — hackathon, community donation drives, MUN
- Beyond the screen — sports
- Education — VIT Vellore timeline
- Connect — LinkedIn / GitHub

## Run locally

```bash
python3 -m http.server 3000
# open http://localhost:3000
```

## Tech

- HTML5
- CSS3 (custom properties, grid, responsive breakpoints)
- Vanilla JavaScript (IntersectionObserver scroll reveal, mobile nav)
